# Small tools for repeat work

LaptekTools makes small, free utilities for specific jobs. These are experimental tools, with their supported formats and limits written in each repository.

| When you need to… | Tool | What it does |
|---|---|---|
| Prepare the same columns from each new CSV export | [CSV Recipe](https://github.com/LaptekTools/csv-recipe) | Select, reorder and rename existing fields; save a local JSON recipe. UTF-8 comma CSV only, exact headings, no missing-field enrichment. |
| Inspect selected Syncthing conflict copies before deciding what to keep | [Conflict Preview](https://github.com/LaptekTools/conflict-preview) · [Browser tool](https://laptektools.github.io/conflict-preview/offline/index.html) | Read-only comparison of selected local files. Does not merge, delete or resolve synchronization conflicts for you. |
| Preview explicit imports for a Python snippet | [Snippet Imports](https://github.com/LaptekTools/snippet-imports) | Local preview using the standard library. Does not execute supplied code or resolve your project's full runtime environment. |

The CSV source is public; its hosted browser page is still being verified. Use each README for the current run instructions. Browser tools process selected file contents in the tab; the hosting provider still receives ordinary page requests. These utilities have no account, checkout or file-upload endpoint.

## Feedback from an actual task

Open an issue in the relevant tool's repository with the job you tried, your previous method and what failed. If you used it again on a second export or task, describe that too. Include your time spent checking the output; download counts and stars alone do not tell us whether it helped.

Please use fictional examples. Do not post customer files, personal data, passwords or tokens. Current source is free under the licenses in its repositories; nothing is for sale here. The tools were developed with AI assistance and tested within the scopes recorded in their READMEs. Real customer usefulness is still being evaluated.
